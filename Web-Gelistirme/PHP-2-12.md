Temel PHP ve MySQL Kullanımı****

PHP, HTML'le rahatça kaynaşabilmesi ve MySQL ile ODBC gibi hiçbir geçide ihtiyaç duymadan konuşabilmesi sayesinde, veritabanlarını internet üzerinden erişilebilir kılmak isteyen kullanıcılar tarafından her geçen gün daha fazla kullanılmaktadır. Bu yazıda, PHP ile MySQL'in beraber kullanımını inceleyecek, temel SQL komutlarını kullanarak ufak bir program yazacağız. Programımızda kullanacağımız veritabanı için gerekli yapıyı, phpMyAdmin programını kullanıyorsanız, aşağıda yer alan kodu kopyalayıp bu programın SQL komutlarının yazıldığı kutuya yapıştırarak kolayca kurabilirsiniz. Eğer MySQL'e komut satırından erişiyorsanız, bir aşağıda yer alan komutları sırasıyla uygulamanız gerekiyor. Veritabanını yaratmak için gereken SQL satırı aşağıdaki gibidir :

CREATE TABLE table1 (

id int(10) unsigned DEFAULT '0' NOT NULL auto\_increment,

ad varchar(50) NOT NULL,

mail varchar(100) NOT NULL,

msj varchar(255) NOT NULL,

tarih date DEFAULT '0000-00-00' NOT NULL,

saat time DEFAULT '00:00:00' NOT NULL,

PRIMARY KEY (id),

KEY id (id),

UNIQUE id\_2 (id)

);

Eğer veritabanını komut satırından kullanıyorsanız, aşağıdaki işlemleri yapmalısınız :

mysql> create database pot01;

mysql> use pot01;

mysql> create table table1 (id int(10) not null auto\_increment,

mysql> ad varchar(50) not null,

mysql> mail varchar(100) not null,

mysql> tarih date default '0000-00-00' not null,

mysql> saat time default '00:00:00' not null,

mysql> primary key (id), key id (id), UNIQUE id\_2 (id)

mysql> );

mysql> quit;

Kısaca kullandığım komutları açıklayayım : **create database**** veritabanı\_adı**: Kullanımı çok basit. Sonuna veritabanı ismini ve noktalı virgülü ekliyorsunuz. Mysql'de çalıştırmak istediğiniz her komutun sonuna noktalı virgül eklemelisiniz. **use**** veritabani\_adi**: Kullanacağımız veritabanını seçiyoruz. **quit**: MySQL istemcisinden çıkış için. MySQL sunucusu ile karıştırmayın, Quit ile istemciden çıkmanızın sunucunun işleyişi ile bir alakası yoktur.

Artık PHP ve HTML kodlarımızı yazmaya başlayabiliriz. Buradaki kodların hepsini içeren ZIP dosyasını mysqlkullanim.zip <http://www.php.org.tr/kodlar/mysqlkullanim.zip> indirebilirsiniz. Daha az karışık olması için kayıt ekleme, kayıt silme, kayıt listeleme, kayıt görüntüleme ve kayıt düzeltme bölümlerini ayrı ayrı PHP sayfalarında yapmayı uygun gördüm. Daha sonra bunları tek sayfada toplamayı da göstereceğim. İlk olarak algoritmayı açıklayacağım. Aşağıda yazılanların tümünü okumak veya yapmak zorunda değilsiniz. Siz işinize yarayacak kısmı seçin. Kodları mümkün olduğu kadar basit tutuyorum, süslemesi sizin yaratıcılığınıza kalmıştır. Öncelikle HTML ile hazırlanmış kayıt girişi için kullanılacak bir formumuz olacak. (Ben çok basit bir örnek vereceğim. Siz bunu isterseniz Frontpage veya benzeri bir programla süsleyebilirsiniz.) Daha sonra formdan yollanan değişkenleri MySQL'de hazırladığımız veritabanındaki tabloya kaydeden bir PHP sayfası hazırlayacağız. Numarasını gönderdiğimiz kaydı silen PHP kodlarını yazacağız. Numarasını gönderdiğimiz kaydı görüntüleyen php kodlarını yazacağız. Tüm kayıtları alt alta listeleyen PHP kodlarını yazacağız. Son olarak, numarasını gönderdiğimiz kayıt üzerinde düzeltme (değiştirme) yapan php kodlarını yazacağız. Not: Siyah yazilar HTML kodları, kırmızı yazılar ise php kodlarıdır. Turuncu yazılar php içinden HTML çıktısı vermek için kullanılmıştır. Yeşil yazılar ise işlem görmeyecek satırlardır, sadece açıklama için kullanılmışlardır. Yeşil satırları çıkartabilirsiniz..
