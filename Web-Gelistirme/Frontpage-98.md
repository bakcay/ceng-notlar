# Frontpage 98

## **F****RONT****P****AGE****’98 **

***WWW nedir?***

WWW (World Wide Web), insanların birbirleriyle elektronik olarak haberleşmesini sağlayan internet ağına denir. WWW’deki her bilgisayar Web Sunucusu adını alır ve birçok farklı HTML dosyası içerir.

***FrontPage Nedir?***

Profesonel bir programcı olmadan Web siteleri oluşturmanıza imkan tanıyan bir programdır.

***FrontPage’de Neler Yapılabilir?***

Bir Web sitesi planlanabilir,

Web sayfaları kolayca oluşturulabilir,

Grafik dosyalarınız üzerinde düzenlemeler yapabilir,

Sitenizi ilgili internet adresine gönderebilir,

Birçok hazır şablonlar kullanılabilir...

***FrontPage Programı Şu Bileşenlerden Oluşur:***

FrontPage Explorer

Task Manager

FrontPage Editor

Image Composer

Publishing Wizard

## **FrontPage Explorer**

FrontPage Explorer Web genelinde seçenekleri yönetmek ve kontrol etmek için kullanılır. Bütün Web Yaratma sürecindeki işlemlerin merkezidir. Burdan diğer bileşenlere (Page Editor, Image Editor...) de ulaşılabilir.

**Views (Görünümler): **

FrontPage Explorer’ın sol tarafında bulunan yedi farklı görünümü sağlayan simgeler bulunmaktadır.

***Folders : ****Web’deki tüm alt dizinleri ve alt dizin içinde bulunan HTML ve resim dosyalarını gösterir. Alt dizinler arasında dosya yer değişikliği yapılabilir.*

***All Files : ****Web’deki tüm dosyaları alt alta listeler.*

***Navigation : ****Web sayfaları arasında otomatikleşmiş gezinti çubukları oluşturur. Sayfaların Anasayla olan ilişkisini şekiller üzerinde gösterimini sağlar.*

***Hyperlinks : ****Web’deki her dosyanın bir diğeriyle olan bağlantısını hiyerarşik bir yapıda grafiksel olarak gösterir.*

***Hyperlink Status : ****Web’deki her bağlantının doğruluğunu otomatik olarak test eder.*

***Themes : ****Burada birçok hazır tema sunulur. Sitenizin metin rengi, başlık grafiği, arka plan resimleri gibi bir motif seçim yeridir.*

***Task : ****Tamamlanması istenen görevlerin bir listesini verir. İstenen görevler not edilir.*

****FrontPage Explorer Toolbar (Araç Çubukları): **

***Create New Page : ****Yeni bir Web Sayfası oluşturur. Mevcut şablon özelliklerini kullanır.*

***Create New Task : ****Yeni görev eklemek için kullanılır.*

***Publish FrontPage Web : ****O an geçerli olan Web’i yayınlar.*

***Open FrontPage Web : ****Mevcut bir FrontPage Web açar.*

***Print Navigation view : ****Navigation görünümünü kağıda basar.*

***Cross File Find : ****Verilen bir kelimeyi tüm Web içerisinde arar.*

***Cross File Spelling : ****Web deki tüm yazıların yazım imla kuralına uyup uymadığını kontrol eder.*

***Cut : ****Seçilen yazı, resim veya dosyayı kesip Clipboard’a aktarır.*

***Copy : ****Seçilen yazı, resim veya dosyanın bir kopyasını Clipboard’a aktarır.*

***Paste : ****Clipboard’daki yazı, resim veya dosyayı bulunulan yere yapıştırır.*

***Del : ****Seçilen yazı, resim veya dosyayı siler.*

***Hyperlinks To Images : ****Bağlantılı dosyaları simgeleriyle birlikte gösterir.*

*** Repeated Hyperlinks : ****Bağlantılı dosyaları simgeleriyle birlikte gösterir.*

*** Hyperlinks Inside Page : ****Sayfadaki linkleri gösterir.*

***Verify Hyperlinks : ****Linklerin bağlantılarını kontrol eder.*

***Up One Level : ****Bir üst dizine geçmeyi sağlar.*

***Rotate : ****Navigation kutularının yerini değiştirir.*

***Size of Fit : ****Navigation kutularını ekrana sığacak şekilde otomatik ayarlar.*

*** Show FrontPage Editor : ****FrontPage Editor programını açar.*

*** Show Image Editor : ****Image Composer grafik programını acar.*

***Stop : ****Publish işlemini kesmek için kullanılır.*

***Help : ****Üzerinde bulunulan konu hakkında yardım ekranını acar.*
